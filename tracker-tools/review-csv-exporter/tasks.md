# Task

## Requirement

A Node command line tool that reads proposal files and a tracker export and writes consolidated review CSVs, one wide row per record in the column format agreed from the sample workbook, for adds, updates and suggestions alike, ordered by what needs the lead's judgment, preserving the lead's review decisions on refresh and never writing to the tracker. It is the exporter the Discovery Orchestrator runs. Depends on the Sample Tracker Workbook being built and its format reviewed by the team; the plan is a first draft to refine after that feedback. Excludes the sample workbook, the infrastructure scope and the `same as` shortcut.
