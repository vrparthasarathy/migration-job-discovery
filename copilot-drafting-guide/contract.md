# Contract

## Contract

### Prompt input and output

| Part | Content |
| --- | --- |
| Input | The job's source code (or the part that fits), the blank template, and optionally the job's use case name. |
| Output | One filled-in document that uses only the template's sections; every statement labelled `CUR-`, `ASM-`, `CHG-` or `MIG-` (draft writes no `MIG-` item); each `CUR-` item with a file-and-place pointer; open questions where the source is silent; a list of unread parts; the acknowledgement left blank. |

### Guidance file

| Part | Content |
| --- | --- |
| Usage | How to run the prompt in Copilot Chat, how to split large source, and how to review the draft against the source. |
| Model advice | Task categories and the client-reported models, marked client-reported and environment-dependent, with a valid-as-of date, a re-check step and a reminder to use the model picker. |
| Review reminder | Copilot output is a draft for human checking. |
